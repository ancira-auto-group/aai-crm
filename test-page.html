Expected Results

The AI should:

  • Fix all grammar and spelling errors
  • Improve sentence structure and flow
  • Maintain the original meaning and key details
  • Use professional but friendly tone
  • Make the text more customer-focused
  • Preserve specific information (names, dates, prices, models)
  • Return concise, natural-sounding text

Troubleshooting

Button Doesn't Appear

  • Make sure you've selected at least 10 characters
  • Check that the extension is loaded in chrome://extensions/
  • Verify the content script is running (check browser console)
  • Ensure you've added test domain to manifest.json matches

API Errors

  • "API key not configured" - Go to extension settings and add your OpenAI API key
  • "Invalid API key" - Check that your key is correct and active
  • "Rate limit exceeded" - You've hit your OpenAI usage limit
  • "Request timeout" - Check your internet connection

Enhancement Quality Issues

  • Try "Mix It Up" to regenerate with different wording
  • Use "Add Some Flair" to give more specific instructions
  • Update your system prompt for better results
  • Ensure your prompt is clear about tone and style preferences
