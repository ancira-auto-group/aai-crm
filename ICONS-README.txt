CHROME EXTENSION ICONS REQUIRED
================================

This extension requires three icon files in PNG format:

Required Files:
  - icons/icon16.png  (16x16 pixels)
  - icons/icon48.png  (48x48 pixels)
  - icons/icon128.png (128x128 pixels)

Recommended Design:
  - Purple/violet gradient background (#667eea to #764ba2)
  - White sparkles, magic wand, or "AI" symbol
  - Simple, recognizable design
  - Professional appearance

Quick Creation Methods:

1. Online Icon Generators:
   - https://www.favicon-generator.org/
   - https://realfavicongenerator.net/
   - Upload a single 128x128 image, it will generate all sizes

2. AI Image Generators:
   Prompt: "Chrome extension icon, purple gradient background, white sparkles,
   professional, modern, flat design, 128x128 pixels"

   Tools:
   - DALL-E (OpenAI)
   - Midjourney
   - Stable Diffusion

3. Design Tools:
   - Canva (free templates)
   - Figma (vector design)
   - Adobe Express (quick icons)

4. Placeholder Icons:
   For testing purposes, you can use any 16px, 48px, and 128px PNG images.
   Just rename them to icon16.png, icon48.png, and icon128.png.

Installation:
  Once you have the icons, place them in the icons/ folder:

  chrome-extension/
    icons/
      icon16.png
      icon48.png
      icon128.png

The extension will not load without these icons!
